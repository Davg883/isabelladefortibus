# Isabella de Fortibus: Countess, Castle, Crown - #VIBEThroughTime

This project is a single-page, scrolling, interactive, and fully responsive webpage detailing the life and times of Countess Isabella de Fortibus at Carisbrooke Castle (c. 1263-1293) for the '#VIBEThroughTime' social media campaign.

## Project Description

The webpage aims to provide an engaging and informative visual story of Countess Isabella de Fortibus, blending historical visuals with modern web design principles. It includes various sections covering her life, her impact on Carisbrooke Castle, daily life within the walls, her political influence, and her legacy. Interactive elements and animations are included to enhance the user experience.

## How to View

To view the webpage, simply open the `index.html` file located in the root directory of this project in your web browser.
